# DistroHub

Каталог и навигатор по дистрибутивам Linux: 20 систем, подбор за пять вопросов,
сравнение бок о бок, гайды, отзывы и избранное. Проект сделан как учебный, но по
архитектуре и объёму ближе к небольшому продукту.

## Быстрый старт: один файл

Самый простой способ открыть проект: файл **`DistroHub.html`**. Он лежит в корне
`distrohub/` и в корне рабочей папки. Файл автономный: внутри уже есть данные,
стили, JavaScript, шрифты и логотипы. Достаточно дважды щёлкнуть по нему: сервер,
`localhost` и интернет не нужны.

В автономной версии работают:

- каталог с поиском, фильтрами и сортировкой;
- карточки всех 20 дистрибутивов;
- интерактивные превью: терминал, файлы, браузер, магазин приложений и настройки;
- мастер подбора из пяти вопросов;
- сравнение до трёх систем;
- гайды и оглавление;
- тёмная и светлая темы;
- избранное, локальный профиль и отзывы.

Избранное, имя и отзывы сохраняются в `localStorage` браузера. Это значит, что
они привязаны к браузеру и не синхронизируются между устройствами: для файла без
сервера это ожидаемо.

Пересобрать файл после изменений:

```bash
npm run build:offline
```

Сборщик находится в `offline/build.mjs`, исходники автономной версии: в
`offline/`. Он генерирует данные отзывов из SQLite, встраивает логотипы, собирает
React-приложение через esbuild и компилирует Tailwind CSS.

## Полная версия на Next.js

В папке также находится полноценное приложение с сервером, SQLite, регистрацией,
JWT-сессиями и API.

### Требования

- Node.js 22.12+ (проект проверен на Node 22.22.2);
- npm.

### Установка

```bash
npm ci
npm run seed
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Демо-аккаунт:

- e-mail: `demo@distrohub.ru`
- пароль: `demo12345`

### Переменные окружения

Создайте `.env.local` при необходимости:

```env
AUTH_SECRET=замените-на-длинную-случайную-строку
NEXT_PUBLIC_SITE_URL=http://localhost:3000
DISTROHUB_DATA_DIR=./data
```

`AUTH_SECRET` используется для подписи JWT-cookie. В production задайте своё
значение. База по умолчанию лежит в `data/distrohub.db` и не коммитится.

### Production

```bash
npm run build
npm start
```

В `next.config.ts` включён standalone-вывод. `postbuild`-скрипт автоматически
копирует статические файлы и `public/` в `.next/standalone`, поэтому `npm start`
запускает готовый сервер из корня проекта.

## Скрипты

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер Next.js |
| `npm run build` | production-сборка Next.js |
| `npm start` | запуск production-сборки из `.next/standalone` |
| `npm run build:offline` | собрать автономный `DistroHub.html` |
| `npm run seed` | заполнить SQLite демо-данными |
| `npm test` | тесты логики каталога и мастера подбора |
| `npm run typecheck` | проверка TypeScript |

## Стек

- Next.js 16.4.3 (App Router), React 19.3.1, TypeScript 5.9.3;
- Tailwind CSS 4.3.3, собственная дизайн-система;
- better-sqlite3 13.0.3, bcryptjs, jose, zod;
- lucide-react;
- Vitest 3.2.7;
- esbuild + PostCSS/Tailwind для сборки автономного файла.

## Структура

```text
distrohub/
├─ src/
│  ├─ app/                 страницы и API Next.js
│  ├─ components/          UI-компоненты
│  ├─ data/                20 дистрибутивов, 6 гайдов
│  └─ lib/                 каталог, рекомендации, БД, auth
├─ offline/
│  ├─ main.tsx             роутер и оболочка автономной версии
│  ├─ pages/               страницы автономной версии
│  ├─ build.mjs            сборка в один HTML
│  └─ offline.css          Tailwind + дизайн-система
├─ public/logos/           логотипы дистрибутивов
├─ data/distrohub.db       демо-база
├─ DistroHub.html          готовый автономный файл
└─ scripts/seed-demo.ts    наполнение базы
```

## Возможности полной версии

- регистрация и вход, httpOnly JWT-cookie, bcrypt-хеши паролей;
- избранное и отзывы в SQLite;
- рейтинги и распределение оценок;
- мастер подбора с объяснением рекомендаций;
- сравнение характеристик;
- гайды с оглавлением, прогрессом чтения и копированием команд;
- адаптивная вёрстка, тёмная/светлая тема, command palette по `⌘K`;
- интерактивные live-превью дистрибутивов с эмуляцией рабочего стола и командной строкой;
- SEO: metadata, sitemap, robots, Open Graph.
