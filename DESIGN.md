# Orbital: дизайн-направление DistroHub

Записано, чтобы решения не переизобретались на каждой правке. Правила фильтра: antislop (core + ui + copywriting + human + layoutmobile), режим `during`.

## Design Read

Справочник дистрибутивов для человека, который выбирает систему и хочет понять разницу до установки. Язык: техническая спецификация и типографский справочник, а не лендинг SaaS.

Диалы:

- ENERGY 2 из 5. Спокойный графит и бумага, один сигнальный цвет, без вспышек.
- RHYTHM 3 из 5. Секции чередуются по композиции: табличный список, bento-витрина с ведущей карточкой, две колонки, узкая полоса, двуколоночный финал со спецификацией.
- MOTION 2 из 5. Появление при скролле, наклон карточки за курсором, параллакс сцены, счётчики. Всё отключается через `prefers-reduced-motion`.

## Палитра

Графит `#07070b`, тёплый белый `#f4f1e8`, один акцент `#ff5c38`. Светлая тема: бумага `#f3efe7`, тот же акцент в глубоком тоне `#bd3410` (контраст на бумаге 5.0:1, на поверхности 5.4:1).

Фиолетовый и мятный из декора убраны: шесть цветов на экране читаются как палитра по умолчанию, а не как бренд. Цвет в интерфейсе остаётся в двух местах: акцент и настоящие скриншоты рабочих столов, где цвет дают сами дистрибутивы. Служебные состояния (успех, предупреждение, ошибка) сохраняют смысловые цвета и используются только по назначению.

## Типографика

- Unbounded: заголовки. Широкий геометрический гротеск с полной кириллицей, держит крупный кегль без засечек.
- Manrope: текст. Нейтральный, хорошо читается в 15–17px.
- IBM Plex Mono: данные и подписи. Только там, где значение является полем данных: индекс секции, версия, счётчик, размер файла.

Прописные с разрядкой применяются к служебным меткам, не к заголовкам.

## Идентичность вместо декора

Мотив спецификационного листа: волосяные линии, угловые засечки вокруг 3D-сцены, индексы вида `02 · выбор редакции`, нумерованная строка каталога, таблица характеристик в финальном блоке. Мотив вытекает из задачи продукта: он сравнивает системы по полям. Это же даёт различие между секциями без смены палитры.

3D-сцена hero остаётся: она показывает настоящий рабочий стол, а не абстракцию. Орбиты вокруг неё тонкие, без свечения и без цветных точек, вращаются медленно как обозначение каталога вокруг одной системы.

## Доступность

- Контраст: muted 6.07:1 на фоне и 5.81:1 на поверхности (тёмная тема), 4.88:1 и 5.32:1 (светлая). Акцент как текст: 6.55:1 и 5.0:1.
- Мишени касания на мобильном не меньше 44px для кнопок хедера, чипов фильтра, ссылок подвала и строки каталога.
- Фокус видимый на всех интерактивных элементах, порядок табуляции начинается с «Перейти к содержимому».
- `prefers-reduced-motion` гасит анимации и появление блоков.
